# Shrihari's Engineering Portfolio

A personal engineering portfolio built through hands-on, project-based learning, exploring frontend development, backend engineering, API design, authentication, and full-stack application architecture.

The project reflects my learning journey in **TypeScript, React, FastAPI, and modern web engineering**, with an emphasis on understanding how individual technologies work together to build a complete application.

## Technology Stack

**Frontend**
- React 18
- TypeScript
- Vite
- React Router
- TanStack Query
- CSS

**Backend**
- Python
- FastAPI
- SQLAlchemy 2
- PostgreSQL
- Alembic

**Authentication & Security**
- Session-based authentication
- HTTP-only secure cookies
- CSRF protection
- Argon2id password hashing
- Role-based access control

**Storage & Infrastructure**
- S3-compatible object storage
- Local file storage for development
- Docker
- Vercel (frontend deployment)
- Railway (backend deployment)

## What I Explored and Implemented

- Building reusable, component-driven interfaces using React and TypeScript.
- Designing responsive layouts and interactive UI components.
- Structuring frontend applications with modular components and routing.
- Integrating frontend applications with REST APIs.
- Managing asynchronous server state and API interactions.
- Building backend services and structured API endpoints using FastAPI.
- Implementing authentication, session management, and access control.
- Working with relational databases, SQLAlchemy, and schema migrations.
- Handling file uploads, validation, versioning, and controlled downloads.
- Understanding frontend-backend integration, environment configuration, and deployment architecture.
- Writing tests for frontend interactions, backend logic, and API behaviour.

## Learning Approach

This portfolio represents an iterative learning process driven by implementation, experimentation, debugging, and refinement.

Rather than learning technologies in isolation, I explored them by applying concepts to a working application and understanding the engineering decisions involved in connecting the frontend, backend, database, authentication, and storage layers.

The goal is to continue improving my understanding of software engineering through practical development.
